# Daily Productivity Tracker

A simple Daily Productivity Tracker built using HTML, CSS, and JavaScript.

Users can add tasks, edit tasks, delete tasks, mark tasks as completed, filter tasks by date, and track daily productivity through an efficiency percentage dashboard.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as Completed or Pending
- Filter tasks by date
- Dashboard statistics:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
  - Efficiency Percentage
- Data persistence using Local Storage
- Responsive UI
- No login required

---

## Efficiency Calculation

Efficiency = (Completed Tasks / Total Tasks) × 100

Example:
- Total Tasks = 10
- Completed Tasks = 8  
- Efficiency = 80%

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
